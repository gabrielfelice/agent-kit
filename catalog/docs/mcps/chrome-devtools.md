Dá ao agente controle de um Chrome real, com janela visível, para você acompanhar enquanto ele navega e testa. Ele pode ler o console, inspecionar requisições de rede, medir performance, rodar o Lighthouse e investigar CSS. É o mais indicado para depurar.

Usa o Chrome estável instalado na máquina, com perfil persistente (`~/.cache/chrome-devtools-mcp/chrome-profile`): logins feitos ali continuam valendo nas próximas sessões. No WSL, o Chrome precisa estar instalado dentro do Linux, e a janela aparece pelo WSLg.
