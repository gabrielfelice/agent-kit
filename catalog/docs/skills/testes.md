Guia prático para criar, configurar e revisar testes automatizados. Complementa a rule `tests`, que é instalada junto e continua obrigatória.

- Testes rápidos, independentes, repetíveis e que validam com assertions de verdade, isolando rede, banco, relógio e aleatoriedade.
- Cada teste cobre um comportamento, organizado em Given/When/Then ou AAA.
- A suíte segue a pirâmide (unidade, integração, E2E), usando as ferramentas que o projeto já adota.
- Antes de concluir, o agente confere se os fluxos críticos foram priorizados e se cada teste protege o que diz proteger.
